# Pulpería La Colineña — GitHub Pages

Esta carpeta está preparada para publicarse directamente con **GitHub Pages**.

- `index.html` es la página de inicio pública.
- Las páginas visibles funcionan con HTML, CSS y JavaScript.
- El apartado usa `localStorage` como demostración en el navegador.
- La versión PHP + MySQL original está conservada en `php-version/` para revisión del código.

## Publicar
1. Sube todo el contenido de esta carpeta a la raíz de un repositorio público de GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, elige **Deploy from a branch**.
4. Selecciona `main` y `/(root)`.
5. Guarda y abre el enlace que GitHub Pages muestre.

> GitHub Pages no ejecuta PHP/MySQL; por eso la parte pública se adaptó a una demostración estática.
